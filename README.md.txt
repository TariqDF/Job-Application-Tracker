# Job Application Tracker

A desktop job application tracker built with C++ and Qt Widgets. The app uses a flashcard-style interface where each card represents a job application.

## Features

- Create, edit, delete, and navigate job application cards
- Save and load data using JSON
- Search and filter applications by status and text
- Status color coding for application progress
- Swipe actions with animation
- Drag-based card interaction
- Grid view for viewing all cards at once
- Clickable grid cards for quick navigation

## Tech Stack

- C++
- Qt Widgets
- QVector
- JSON persistence with QJsonDocument, QJsonArray, and QJsonObject
- QPropertyAnimation
- Custom QWidget/QFrame subclassing

## Project Purpose

This project was built to practice desktop application development, UI state management, custom Qt widgets, event handling, animation, and data persistence in C++.
